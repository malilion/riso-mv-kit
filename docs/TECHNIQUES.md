# 技巧與模式

這份文件說明這套 MV 的畫面是怎麼做出來的，以及做新場景時可以沿用的寫法。每一節都標了對應的程式位置。

---

## 1. 孔版印刷引擎（`engine/riso.js`）

真正的孔版印刷是一個顏色一個版（drum），每印一色就過一次機器。引擎照這個方式運作：

- **畫在色版上，不是畫顏色**：場景畫的是「這裡要多少油墨」（canvas 的 alpha 就是油墨濃度），共有五個版：`k`（線稿）、`a`、`b`、`c`、`d`。最後由 `RISO.print()` 決定每個版上什麼油墨，再在 GPU 上合成。
- **疊印是相乘**：油墨是半透明的，黃疊藍會變綠。合成時把每個版的顏色乘在紙色上。
- **兩種畫法**：
  - `P.paint(path, {a: .8})` 不透明：先把所有版在這塊區域挖空，再上墨，適合前景物件。
  - `P.add(path, {c: .3})` 疊印：直接加上去，適合光、陰影、漸層。
  - `P.erase(path)`：挖成紙白。
  - `P.stroke` 畫線，`P.outline` 只描聯集的外框（例如雲朵由很多圓組成，只描最外圈）。
- **半色調網點**：濃度不到 1 的地方會變成網點，每個版的網點角度不同（15°、45°、75°……），疊起來就是印刷品的玫瑰花紋。可以在 `screens` 設定角度、網點大小和模式：`1` 是網點，`2` 是顆粒，例如鉛筆稿用顆粒。線條一律用實心印，避免被網點切成虛線。
- **套色錯位**：每個版有固定的偏移，每次印刷再隨機抖動約 1 像素。
- **油墨不均和紙**：色塊裡有斑駁和缺墨的小白點，紙有纖維和凹凸，最後加上顆粒和暗角。

## 2. 一拍二與重印（`engine/core.js`）

- `onTwos(t)` 把時間量化到每秒 12 張，`boilSeed(t)` 每張換一次亂數。
- 線條透過 `boil()` 和 `curve()` 每張都微微抖動，印刷的錯位和油墨斑駁也每張重抽。所以畫面像一本手繪、再一張張印出來的翻頁書。
- 鏡頭位置、文字浮現用連續時間 `t`，維持每秒 30 格的流暢。**手作感的部分用 `tt = onTwos(t)`，要順的部分用 `t`。**

## 3. 繪本素材（`engine/draw.js`、`engine/kit.js`）

- `curve(points, closed, t)`：通過點的平滑曲線，再加上抖動，所有手繪形狀都從這裡來。
- `blob` 不規則圓、`cloudPath` 雲、`ridge` 山稜線、`leafPath` 葉子、`sunPaths` 太陽和光芒。
- 人物：`walker`（背影）、`walkerSide`（側面走路，回傳兩手位置，方便牽手）、`pair`、`pairSide`、`sitter`（坐著的背影）。造型集中在 `LOOK`，用各版的濃度描述衣服和頭髮的顏色。
- `kit.js` 的場景積木：
  - 天空：`skyAndHills`（天空、太陽、雲、遠山）、`daySky`（日夜循環的天空）
  - `clockWorld`：時鐘小星球，一圈就是一天
  - 天氣與光：`rainFx`（雨，可以留出傘下不淋雨的區域）、`godRays`（雲隙光）
  - 物件：`umbrella`、`blossom`（花苞到盛開）、`TREASURE`（12 種小寶物圖示）
  - 頁面：`chapterPage`（章節頁）、`bookFrame`（繪本外框）
  - 效果：`drumPasses`（開場逐色印出）、`inkProxy`（鉛筆稿淡出）

## 4. 植物生長（`engine/plant.js`）

`sprout(P, x, y, 高度, g, t, 選項)` 的 `g` 從 0 到 1，依序經過真實的發芽階段：

| g | 階段 |
|---|---|
| 0.04–0.30 | 胚軸彎成鉤狀破土，頂著種皮 |
| 0.22–0.46 | 伸直 |
| 0.42–0.58 | 種皮脫落，兩片圓圓的子葉展開 |
| 0.56–0.95 | 頂端長出一對尖的本葉 |
| 0.86–1.00 | 花苞 |

- 選項：`stemK`（莖長倍率）、`leafK`（子葉大小）、`thick`（粗細）、`sway`（搖擺）、`bud`、`coat`。短莖加大子葉，就是一整片可愛的雙葉。
- **讓生長對準音樂**：不要用線性時間，改用 `keys(lt, [[0, .02], [B * 3.6, .44], [B * 4, .52], ...])` 這樣的關鍵影格，讓子葉剛好在重拍上打開。

## 5. 一路延伸的道路（`engine/road.js`）

偽 3D 道路（類似 OutRun 的分段投影）：

- 路由許多段組成，每段有彎度和高度，把彎與坡疊起來就是一路上下起伏的鄉間路。
- **地面由近畫到遠**，每條地面帶只畫還沒被更近的山丘擋住的部分，所以可以直接疊印，不用挖空。
- **路邊物件由遠畫到近**，並裁切到更近的地形之後，所以會正確地被山丘擋住。
- 田地是平行於道路、往地平線收斂的條狀，每塊種不同作物（不同濃度和色版組合）。遠處會加上空氣透視的藍。
- `blank: [起, 訖]` 讓遠方淡出成**還沒印的紙**，只剩鉛筆線，用來表現「看不見的前方」。

## 6. 歌詞排版（`engine/type.js`）

- 日文直書，每個字依自己的時間印出來，帶一點彈性縮放。時間的分配依字的份量：假名 1、小假名 0.45、漢字 1.6、空格是停頓。
- 歌詞有空格時，可以在 `parts` 給每段自己的時間窗，逐字浮現會在換氣處停住。
- 一行放不下會自動平均分成兩行，小假名會往右上偏。
- 每個字周圍會在所有色版挖出一圈紙白（`haloText`），所以在任何背景上都讀得清楚。中文字幕用霞鶩文楷，放在下方。
- `lyricIdx(t)` 找出目前要顯示的句子；`lyr(P, t, 位置)` 一次畫好日文和中文。

## 7. 時間軸與節拍（`engine/timeline.js`、`tools/analyze.mjs`）

- 歌曲的時間都從 `song.json` 的 `bpm` 和 `phase`（第一個重拍）推算，例如 `beatOf`、`barT`、`pulse`。
- 流行歌大多以 8 小節為一個樂句。字幕和人聲通常在小節線後 0.2 秒左右開始，所以場景排在「該句之前的那條小節線」（`barBefore`），轉場剛好在那一刻完成。
- **節奏分析**的做法：
  1. 頻譜通量的自相關，找出 BPM 候選。
  2. 處理快一倍、慢一半的歧義：偏好 80–160 BPM。
  3. ±1.5% 內以 0.01 BPM 細搜：1% 的誤差在一分鐘內就會差一整拍。
  4. 用低頻起音判斷哪一拍是重拍。
  5. 每 20 秒檢查一次拍點漂移，確認節奏固定。

## 8. 轉場（`engine/transitions.js`）

轉場作用在印好的成品（RGB）上，所以前後兩頁可以用不同的油墨。

- `page`：從右下角翻起一頁。翻起的部分沿著摺線鏡射，背面是紙色，並透出一點前一頁的印刷，像紙背透墨。摺線上有高光，被翻開的新頁上有陰影。
- `fade`：淡入。結尾則會整體淡回紙色。

## 9. 開場逐色印出

`drumPasses(P, t, 開始時間)`：每一拍讓一個版的墨從上往下「印」上去。順序依淺到深：黃、綠、粉紅，最後是黑色線稿。在淺色版上可以看到被挖空的區域，和真的分色印刷一樣。

## 10. 鉛筆稿淡出（`inkProxy`）

`inkProxy(P, k)` 用同一套繪圖指令，但把油墨濃度乘上 `k`，並補上一圈鉛筆描線。搭配 `k` 版的顆粒網點（`screens: { k: [45, 6, 2] }`），淡的線條會像鉛筆。可以用來畫「還沒印出來」的東西：遠方、過去、記憶。

## 11. 回憶卡片（`RISO.snapshot`）

`RISO.snapshot(名稱, Q => 某場景(Q, 時間, 開始))` 把另一個場景畫在色版上，存成半尺寸的副本（每個場景只算一次），再當作卡片貼回目前的畫面。適合回顧前面畫過的頁面。畫快照時設定 `window.NO_LYRICS = true`，就不會把歌詞也印進卡片。

## 12. 從歌詞影片讀時間（`tools/video-lyric-scan.js`）

用 2 倍速、靜音播放影片，每一格比對字幕區的白色文字有沒有改變，記下換字幕的時間和「墨量」（文字像素數，大約和字數成正比）。

- 注意：瀏覽器在分頁不可見時不會繪製影片畫面，所以掃描期間分頁要保持顯示。腳本會在切走時暫停、回來時繼續。
- 對應歌詞時：
  - 字數和墨量的比例，可以確認每段對到哪一句。
  - 一段字幕放了兩句：用樂句長度和人聲起音拆開。
  - 同一句被拆成兩段字幕：前後半句各對一段。

## 13. 人聲分析（`tools/vocal.mjs`）

主唱通常在混音的正中央，所以把每個頻率的「中聲道強度減掉側聲道強度」加總，只看 250–3500 Hz。結果能大致看出人聲在哪裡、哪裡換氣。

- 樂團全開的段落雜訊比較多，要搭配樂句結構判斷。
- 安靜的段落非常準。

## 14. 分段渲染（`tools/render_chunks.sh`）

每格 JPG 約 1.3 MB，整首要 10 GB 以上。分段渲染的做法：

1. 渲染一段。
2. 用一樣的 x264 參數合成這一段。
3. 刪掉這段的影格，再做下一段。
4. 全部完成後用 concat 無損接起來，配上音樂和淡出。

中斷後重跑會跳過已完成的段落。渲染器本身也可以續跑：已存在的影格會略過；字型或網路暫時失敗時會自動重試。

## 15. 做新場景時的小原則

- **先決定色版的角色**，例如 `a` 植物、`b` 天空和陰影、`c` 光、`d` 強調色，同一支 MV 盡量一致。這樣回憶卡片、轉場和整體色調才會統一。
- **前景用 `paint`，光影用 `add`**，外框用 `outline`。
- **手作感的動作用 `tt`，鏡頭用 `t`**。
- **重要的動作對準重拍**：用 `barT`、`beatOf`、`keys`。
- **歌詞的位置隨場景調整**，避開主角。有紙白描邊，所以壓在背景上沒關係。
- 先用 `?scene=名稱&t=秒數` 單獨調整一個場景，再放進 `story.js`。
